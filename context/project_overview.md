# Product Requirements Document

## 1. Overview

Create a multilingual compact and minimal personal portfolio that presents my professional profile with the same clarity and structure of a well-designed CV.

The portfolio is designed primarily for recruiters. It prioritizes readability, concise information, and fast navigation over visual effects. The homepage provides a compact overview of my profile, while dedicated project pages allow deeper exploration of selected work.

The overall experience should be minimal, accessible, and easy to maintain as my experience grows. Responsive minimal, clear design.

## 2. Goals

### Primary Goals

- Help recruiters understand my profile in less than one minute.
- Showcase my projects through structured case studies (detailed page with screenshot, diagrams, and text, as if it was a presentation for a thesis).
- Provide immediate access to my contact information, LinkedIn, GitHub, and CV.
- Present information with clear visual hierarchy.
- Support both English and Italian.
- Be easy to update without modifying the application structure.

### Design Goals

- Minimal.
- Professional.
- Clear.
- Concise.
- Consistent.
- Accessible.
- Responsive.

### Design Principles

- Accessibility
- Contrast
- Clear visual hierarchy

## 3. Core User Flow

1. Recruiter opens the homepage.
2. Immediately identifies:
   - who I am
   - current role
   - projects
   - education
   - technologies
   - experience
   - about (personal, non-work)
   - contact links
3. Navigation: a sticky section nav (Projects, Education, Experience, Skills, About, Contacts) appears below the hero, then fixes to the top on scroll. Collapses to a hamburger menu on mobile.
4. Quickly scans the homepage sections.
5. Finds an interesting project.
6. Opens the project page.
7. Reads the project as a structured technical case study.
8. Visits GitHub, LinkedIn, or downloads my CV.
9. Contacts me.

## 4. Scope

### In Scope

- Compact homepage
- Project detail pages
- Responsive layout
- Accessibility
- Internationalization
- Simple animations
- Easy content maintenance

### Out of Scope

- Blog
- CMS
- Authentication
- Admin dashboard
- Backend APIs
- Complex animations
- Contact form backend

## 5. Success Criteria

- The product is successful if:
  - A recruiter understands my profile within one minute.
  - A recruiter reaches a project within two clicks or less.
  - Every project can be understood within five minutes.
  - Contact information is always visible and easy to access.
  - Updating portfolio content requires minimal effort.
  - The interface remains clear on desktop and mobile.
  - Accessibility and readability are never compromised for aesthetics.
